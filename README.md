# FlapGo

FlapGo is a web-based game inspired by Flappy Bird.

## Description
This project is a heavily modified version of an existing Flappy Bird-style game.
Major changes include:
- Complete refactor of game logic
- New UI design and assets
- Modified scoring system
- Additional gameplay features

## Academic Note
This project was developed for academic purposes.
The original repository was used only as a reference.

## How to Run
Open `index.html` in a web browser.
